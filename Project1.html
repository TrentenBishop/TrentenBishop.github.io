Project 1: Crime Rate Analysis

In this project, I conducted an in-depth analysis of the 2023 crime report to uncover trends and patterns within the data. My approach focused on:

  • Data Cleaning: Addressing missing or inconsistent information.
  • Exploratory Data Analysis (EDA): Visualizing crime trends across regions and time.
  • Correlation Analysis: Identifying relationships between crime types and socio-economic factors.
  • Predictive Modeling: Anticipating future crime hotspots using historical data.

This analysis utilized Python, Pandas, and Matplotlib, resulting in actionable insights for improving public safety and policymaking. The project highlights the significance of data-driven solutions in addressing societal issues.
